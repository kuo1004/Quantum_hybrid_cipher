# IRIS 醫療影像系統 整理更動版

### 核心概念

```
醫療人員 (Client)  ⟷  安全通道(經過CA)  ⟷  醫院伺服器 (Server)
   └─ 上傳/下載          └─ 加密傳輸        └─ 資料儲存

```

**關鍵重點**:

- **Client** = 醫療人員的工作站 (有 Sender + Receiver)
- **Server** = 醫院後端伺服器 (有 Receiver + Sender)
- 所有資料最終儲存在 **Server 的資料庫**
- Client 不保存資料，僅用於上傳和瀏覽

## 操控說明
```
# 終端機 1: CA Server
cd CA/
python ca_server.py 8001

# 終端機 2: Hospital Server  
cd server/
#python server_integrated.py 8200 localhost 8001
python server_integrated.py 8200 (ip adress) 8001

# 終端機 3: GUI Client
cd client/
python main.py
(需自行到程式碼更改ip adress連線位址，若是皆由本地開啟 則不需更改)

```

##  完整資料流程


###  上傳流程 (Client → Server)


```
醫療人員工作站 (Client)              醫院伺服器 (Server)
      │                                    │
┌─────┴──────────────────────────────────────────────────────┐
│ 步驟 1: 使用者透過 Web UI 選擇影像上傳                       │
└────────────────────────────────────────────────────────────┘
      │
      ├─► 影像暫存於 Client 的 upload/ 目錄
      │
┌─────┴──────────────────────────────────────────────────────┐
│ 步驟 2: Client 的 Sender 自動處理                           │
│   ├─ 讀取影像檔案                                           │
│   ├─ 加密 (AES-GCM + ML-KEM)                               │
│   │   └─ 使用 Server 的公鑰                                 │
│   ├─ 數位簽章 (Client 的私鑰)                               │
│   ├─ LSB 隱寫術                                            │
│   └─ 產生加密封包                                           │
└────────────────────────────────────────────────────────────┘
      │
      │ 【安全通道傳輸】
      │ Socket/HTTP/共享目錄
      ├───────────────────────────────────────────►
      │                                             │
      │                                    ┌────────┴──────┐
      │                                    │ 步驟 3: 接收   │
      │                                    │   └─ 加密封包  │
      │                                    └────────┬──────┘
      │                                             │
      │                                    ┌────────┴──────────────┐
      │                                    │ 步驟 4: Server 的      │
      │                                    │ Receiver 解密          │
      │                                    │   ├─ LSB 提取          │
      │                                    │   ├─ KEM 解封裝        │
      │                                    │   │   (Server 私鑰)    │
      │                                    │   ├─ AES-GCM 解密      │
      │                                    │   └─ 驗證 Client 簽章  │
      │                                    └────────┬──────────────┘
      │                                             │
      │                                    ┌────────┴──────────────┐
      │                                    │ 步驟 5: 寫入資料庫     │
      │                                    │   ├─ 原始影像 (明文)   │
      │                                    │   ├─ 縮圖              │
      │                                    │   ├─ 元資料            │
      │                                    │   └─ 驗證狀態          │
      │                                    └────────┬──────────────┘
      │                                             │
      │◄──────────────────── 回應：上傳成功 ◄──────┤
      │
┌─────┴──────────────────────────────────────────────────────┐
│ 步驟 6: Client 清理暫存檔案                                  │
│   └─ 刪除 upload/ 中的臨時檔案                               │
└────────────────────────────────────────────────────────────┘

```

```
醫療人員工作站 (Client)              醫院伺服器 (Server)
      │                                    │

      │                                             │

      │                                    │   └─ 回傳影像清單      │
      │                                    │      (縮圖 + metadata)│
      │                                    └────────┬──────────────┘
      │                                             │
      │◄──────────── 回傳影像清單 ◄──────────────────┤
      │              (加密傳輸)                      │
      │                                             │
┌─────┴──────────────────────────────────────────────────────┐
│ 步驟 3: 使用者點擊某張影像，請求完整影像                      │
└────────────────────────────────────────────────────────────┘
      │
      ├───────────── 請求影像 ID=123 ──────────────►
      │                                             │
      │                                    ┌────────┴──────────────┐
      │                                    │ 步驟 4: 從資料庫       │
      │                                    │ 提取影像               │
      │                                    │   └─ 原始影像 (明文)   │
      │                                    └────────┬──────────────┘
      │                                             │
      │                                    ┌────────┴──────────────┐
      │                                    │ 步驟 5: Server 的      │
      │                                    │ Sender 加密            │
      │                                    │   ├─ AES-GCM 加密      │
      │                                    │   │   (Client 公鑰)    │

      │                                    │   └─ LSB 隱寫          │

```
