

結合**量子後密碼學**與**第三方認證機制**的安全檔案傳輸系統，適用於醫療影像等敏感資料的機密傳輸。
**測試指令**
```bash
    python video_test.py video.mp4
```


## 系統架構

### 角色分工
- **KGC (Key Generation Center)**：負責產生並分發公私鑰對
- **加密方 (Encryptor)**：使用公鑰加密檔案並傳送
- **解密方 (Decryptor)**：使用私鑰解密接收的檔案

## 核心檔案

### `kgc_keygen.py` - 金鑰生成中心
**功能**：產生ML-KEM密鑰對並安全分發

**主要特色**：
- 支援ML-KEM-512/768/1024演算法
- 自動產生金鑰ID與元數據
- 提供金鑰驗證功能
- 生成詳細的金鑰報告



### `encryptor.py` - 加密方程式
**功能**：使用第三方公鑰進行混合加密

**加密流程**：
1. 載入第三方公鑰
2. 生成AES-256會話金鑰
3. 透過ML-KEM封裝會話金鑰
4. 使用AES-GCM分塊加密原始檔案
5. 輸出加密檔案(.hyb)與金鑰檔案(.pkl)


### `decryptor.py` - 解密方程式
**功能**：使用第三方私鑰進行混合解密

**解密流程**：
1. 分析加密檔案標頭資訊
2. 載入對應的私鑰
3. 驗證金鑰ID匹配性
4. 透過ML-KEM解封裝會話金鑰
5. 使用AES-GCM分塊解密還原檔案
