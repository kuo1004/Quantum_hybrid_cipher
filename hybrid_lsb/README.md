# 混合加密隱寫系統

結合**量子後密碼學**與**影像隱寫術**的高安全性隱密傳輸系統。

## 核心技術

### 加密技術
- **ML-KEM**：量子抗性金鑰封裝機制，提供安全的金鑰交換
- **AES-GCM**：高效對稱加密，負責實際資料加密

### 隱寫技術
- **LSB隱寫**：將加密資料嵌入影像最低位元中
- 支援RGB多通道操作，視覺上不可察覺

## 運作流程

### 加密階段
1. 使用AES-GCM加密原始影像
2. 透過ML-KEM封裝AES金鑰
3. 將加密資料與金鑰資訊打包
4. 嵌入載體影像的LSB中

### 解密階段
1. 從隱寫影像提取隱藏資料
2. 使用私鑰解封AES金鑰
3. 解密還原原始影像

## 系統優勢

- **量子安全**：抗量子電腦攻擊能力
- **隱密傳輸**：資料隱藏於普通影像中
- **雙重保護**：加密與隱寫雙重安全機制
- **自動化**：提供完整的加解密流程

## 應用場景

適用於醫療影像、機密文件等需要高度保密的資料傳輸場景。
